# AdSkip —— 澎湃 OS 3 跳过广告工具

基于 **无障碍服务（AccessibilityService）+ 悬浮窗手动捕获 + 规则 GitHub 云同步**。

> 无需 root、无需 ADB。事件驱动、零轮询。

## 功能

| 功能 | 说明 |
|------|------|
| **自动跳过广告** | 内置保守关键词（跳过/跳过广告等），界面变化即匹配点击 |
| **悬浮胶囊捕获** | 点击胶囊进入捕获模式 → 点目标按钮 → 自动收录规则 |
| **关键词开关** | 开启覆盖更广，关闭仅用手动规则——最省电 |
| **全局总开关** | 一键暂停/恢复，无需撤销无障碍权限 |
| **规则云同步** | GitHub 仓库上传/下载（合并去重） |
| **前台保活** | 常驻通知 + 开机自启 |
| **点击统计** | 记录每日/每月/每年点击次数和最近点击日志 |
| **防死循环保护** | 同一规则 5 秒内触发 3 次自动关闭总开关 |

## 首次使用

### 1. 安装 APK
下载 `AdSkip-v1.1.apk` 安装。如提示"未知来源"，允许「安装未知应用」。

### 2. 开启三项权限
| 步骤 | 操作 |
|------|------|
| ① 无障碍 | 点「开启无障碍服务」→ 启用 **AdSkip** |
| ② 悬浮窗 | 点「开启悬浮窗权限」→ 允许「显示在其他应用上层」 |
| ③ 电池白名单 | 点「电池无限制 / 自启动白名单」→ 省电策略选**无限制** + 允许**自启动** + 任务栏**锁定** |

> **HyperOS 3**：应用管理里还要开「后台弹出界面」。

### 3. 确认运行
看到「运行中：监听界面并自动跳过」，悬浮胶囊出现，即完成。

## 日常使用

| 操作 | 怎么做 |
|------|--------|
| 自动跳过 | 打开有广告的 App，自动识别并点击「跳过」类按钮 |
| 手动捕获 | 点悬浮胶囊 → 点真实「跳过」按钮 → 自动收录 |
| 暂停/恢复 | 进「规则与同步设置」→ 总开关 |
| 管理规则 | 同上 → 查看/删除关键词与捕获规则 |
| 云同步 | 设置页底部输入密码解锁 |

## 规则云同步

进入「规则与同步设置」→ 底部「规则云同步」：

1. 输入密码 `12345678` 解锁
2. 填仓库 owner/repo/branch/path
3. 下载不填 Token 也能用（公开仓库），上传需 [GitHub Token](https://github.com/settings/tokens)

> Token 经 Android Keystore 加密存储。
